## Anotaciones

Para realizar la primera prueba diagnostica estuve muy confiado de hacerlo tal cual lo aprendí el anterior semestre junto a mis trabajos como guía. Me dedique principalmente al desarrollo del backend con express y CORS donde cree por medio de varias capas una serie de archivos dedicados al manejo de utilidades de la app, la carpeta de tasks contiene 4 archivos, un type, un service, un controller y un router que dividen sus acciones y en conjunto logran realizar las peticiones a api. En los types se encuentran los tipados tal cual la base de datos, en el service se encuentran las funciones con los query para interactuar con la database, el controller recibe los parametros y da una respuesta, y por último el router permite darle una dirección "/" a cada funcionalidad. Despues de eso lo conecto todo a app.ts donde se encuentran agrupadas las funcionalidades del backend y la respectiva dirección de la función de task. Además en el backend hay una carpeta config que contiene toda la configuración necesaria para poder realizar peticiones a supabase. Finalmente, realize pruebas junto a postman donde comprobe el funcionamiento de algunas características como el pedido de todas las tareas en base de datos.

A la hora de realizar el frontend ya tuve que pausar el ritmo de trabajo porque me enfrente a varios problemas con dependencias y la organización de las páginas donde no pude pasar del main.tsx y no pude desarrollar ninguna función propia ya del funcionamiento de la app con una interfaz.
